# Data Card: TMDb Top 10000 Popular Movies Dataset

## Source

- Dataset: TMDb Top 10000 Popular Movies Dataset
- Source: https://www.kaggle.com/datasets/sankha1998/tmdb-top-10000-popular-movies-dataset
- Accessed: 2026-09-09

## Purpose

This dataset supports an analysis of average audience ratings for popular
movies.

## Records and Grain

The dataset contains 10,000 records. Each row represents one movie.

## Variables Used

- `title` — movie title
- `overview` — movie description
- `original_language` — original language code
- `vote_count` — number of audience votes
- `vote_average` — average audience rating on a 10-point scale

## Notes and Limitations

This is a popular-movie dataset. Results describe the movies included in this
dataset and may not represent all movies available in TMDb.
